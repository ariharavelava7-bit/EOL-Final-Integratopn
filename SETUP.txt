========================================
SIMPLIFIED OCTOPART + GEMINI FFF VALIDATOR
========================================

SUPER SIMPLE WORKFLOW:
1. Lookup part
2. Set priorities
3. Download color-coded Excel

NO UI COLOR CODING!
Color coding ONLY in downloaded Excel file.

========================================

REQUIREMENTS:

1. Octopart/Nexar API
   URL: https://portal.nexar.com/sign-up
   Add to .env:
     OCTOPART_CLIENT_ID=your_id
     OCTOPART_CLIENT_SECRET=your_secret

2. Gemini API (optional for AI analysis)
   URL: https://makersuite.google.com/app/apikey
   Add to .env:
     GEMINI_API_KEY=your_key

========================================

FLOW:
1. Octopart → Fetch alternatives
2. Gemini → AI color coding decisions
3. colour.py → Apply colors to Excel
4. Download → Beautiful Excel report

UI: Simple and clean
    - No color-coded tables
    - Just lookup + priorities + download

Excel: Fully color-coded
    - Yellow headers
    - Gray attributes
    - Green/Orange/Red data cells

========================================

SERVERS:
Backend:  http://localhost:8001
Frontend: http://localhost:3001
