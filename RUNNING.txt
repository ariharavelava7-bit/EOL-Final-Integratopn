HOW TO USE:
===========

1. Open browser: http://localhost:3001

2. Enter part number and click "Lookup Specs"
   Examples: LM317, MCP73831T, ATMEGA328P

3. Set priorities for each parameter:
   • Priority 1 = Must Match (Critical)
   • Priority 2 = Can Differ (Acceptable variation)
   • Priority 3 = Cosmetic (Low importance)

4. Click "Download Color-Coded Excel Report"
   → Excel will be generated with beautiful color coding:
      🟨 Yellow headers
      ⬜ Gray attribute column  
      🟢 Green cells = Match
      🟠 Orange cells = Variation
      🔴 Red cells = Missing/Critical difference
